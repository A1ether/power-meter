Power Meter 使用说明

多平台 AI 余额 / 积分看板 · 桌面版

第一次使用

看板本身是一个本地服务，数据来自你自己的账号。第一次打开时账号列表是空的，跟着下面的步骤添加即可。

  1. 点看板右上角的 ＋ 添加账号（或空状态里的 ＋ 添加平台账号）。
  2. 在平台列表里选一个平台，优先用 扫码 / 网页端登录；没有登录入口的平台，在表单里手动填写 Cookie 或令牌。
  3. 添加成功后卡片会自动出现；之后每次打开应用都会读取最新余额。
扫码 / 网页登录需要在 Mac 上安装 Google Chrome。应用会拉起一个独立的调试窗口，和你的日常浏览记录完全隔离。

配置与凭证存在哪里

所有账号与凭证只保存在这台 Mac 上，不上传、不经过任何中转服务：

~/Library/Application Support/PowerMeter/

  • .env：凭证与设置（首次启动自动生成，权限 0600）。
  • accounts.json：账号清单（首次启动为空，添加账号后自动写入）。
  • .run/usage-history.json：本地用量采样，用于计算每日用量。

菜单栏 Power Meter → 打开配置目录 可直接在访达里查看；打开日志 可排查启动问题。

手动配置（少数平台）

大多数平台可以在应用内完成登录。少数只认网页登录态的平台，如果应用内登录不可用，可以编辑配置文件：

  1. 菜单 Power Meter → 打开配置目录。
  2. 用文本编辑器打开 .env，按文件里的注释填写对应平台的变量（如 QWENWORK_COOKIE）。
  3. 保存后无需重启应用，服务会自动热加载；点看板的「立即刷新」即可。

不要在聊天窗口或公开仓库里粘贴 Cookie / API Key。

常见问题

首次打开被 macOS 拦截 在访达「应用程序」里 右键点 Power Meter → 打开，再点「打开」。仍被拦截时，到 系统设置 → 隐私与安全性 点「仍要打开」。应用未做 Apple 公证，这是系统对所有未签名应用的默认提示。
卡片显示「未配置」 该账号的凭证为空或已过期。点卡片右上角的「重新登录」，或在平台弹窗里重新填写。
启动失败 / 窗口空白 打开菜单里的日志文件，通常能看到端口占用或依赖缺失的原因；关闭窗口后重新打开即可重启内置服务。
关闭窗口后还在运行吗 不会。关闭主窗口即退出应用并结束内置服务；下次打开会重新启动。

说明

本应用是本地第三方看板，与各平台官方无关；余额与到期时间以平台接口返回为准。请只添加你本人有权使用的账号。
